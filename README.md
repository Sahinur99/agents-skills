# Antigravity Complete Suite: Agents, Skills, Plugins, Rules & Workflows

Enterprise-grade AI coding agent configuration repository for Google Antigravity and AI harnesses, powered by ECC, Graphify, and official plugins.

## What is in this Repository

| Component | Count | Description |
| :--- | :---: | :--- |
| **Skills** | **314** | Complete domain procedures (Playwright, Graphify, Awesome Design, API design, DevOps, Machine Learning, Security, Full-stack languages). |
| **Agents** | **71** | Autonomous specialized subagent personas (Architects, Reviewers, Planners, Build-Error Resolvers, Security Auditors). |
| **Rules** | **123** | Strict coding standards, deterministic testing guardrails, and quality checks across TypeScript, Python, Go, Rust, Java, C#, C++, and SQL. |
| **Workflows** | **99** | Native slash commands (`/quality-gate`, `/code-review`, `/build-fix`, `/graphify`, `/plan-prd`, `/security-scan`, etc.). |
| **Plugins** | **2** | `awesome-design-md` (100+ production design systems) and `playwright-mcp` (browser testing suite). |
| **Memory Bank** | `docs/` | Persistent architecture patterns (`systemPatterns.md`, `techContext.md`, `activeContext.md`, `mcp-configuration.md`). |

## How to Use in Any Project

1. **Clone this repository** or copy the `.agents/` folder into your project root:
   ```bash
   git clone https://github.com/Sahinur99/agents-skills.git
   ```
2. **Open the project in Antigravity**.
3. All 314 skills, 71 agents, 123 rules, and 99 workflows are discovered and loaded automatically.
4. For persistent memory & GraphRAG, configure your `~/.gemini/config/mcp_config.json` as shown in [`docs/mcp-configuration.md`](./docs/mcp-configuration.md).
