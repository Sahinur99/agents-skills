# Antigravity Agents & Skills Suite

Enterprise-grade AI coding agent configuration repository for Google Antigravity and AI harnesses, powered by ECC and Graphify.

## Overview
This repository contains a full suite of autonomous subagents, skills, rules, and workflows to ensure high-reliability coding, persistent architectural memory, and zero regressions.

- **Skills (302):** Specialized procedure runbooks across API design, cloud infra, frontend, backend, security, testing, and optimization.
- **Agents (71):** Dedicated subagent roles (Architects, Reviewers, Planners, Build-Error Resolvers, Security Auditors).
- **Rules (123):** Coding style standards, error handling, and test-driven development guardrails across TypeScript, Python, Go, Rust, Java, C#, and SQL.
- **Workflows (99):** Executable slash commands (`/quality-gate`, `/code-review`, `/build-fix`, `/graphify`, etc.).
- **Memory Bank (`docs/architecture/`):** Living architectural blueprints and persistent context.

## Usage in Any Project
To use these agents and skills in any project:
1. Clone or copy the `.agents/` folder into your project root.
2. Open the project in Antigravity.
3. All skills, rules, and agents are automatically discovered and ready to use.
